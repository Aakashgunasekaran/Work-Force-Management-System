# Work-Force-Management-System

A Java-based Workforce Management System developed using Object-Oriented Programming (OOP) principles to simplify employee management, attendance tracking, leave handling, payroll management, and department organization.

## 📌 Features

- Employee Management
- HR Management
- Manager Management
- Developer Management
- Attendance Tracking
- Leave Management
- Payroll Management
- Department Management
- Shift Management
- Employee Document Management
- Menu-driven Console Application

---

## 🛠️ Technologies Used

- Java
- Maven
- Object-Oriented Programming (OOP)
- IntelliJ IDEA

## ▶️ How to Run

### Clone the Repository

```bash
git clone https://github.com/your-username/WorkforceManagementSystem.git
```

### Navigate to Project

```bash
cd WorkforceManagementSystem
```

### Compile

```bash
mvn compile
```

### Run

```bash
mvn exec:java
```

or run `Main.java` directly using IntelliJ IDEA.
